# Портфолио проектов с фильтрацией (React)

Учебный проект для отработки навыков управления состоянием и взаимодействия компонентов в React.

Приложение представляет собой веб-галерею работ, которую можно фильтровать по категориям (Websites, Flayers, Business Cards) с помощью панели инструментов.

## Цель проекта

* Научиться управлять состоянием приложения в классовых компонентах (`state`, `setState`).
* Реализовать архитектуру «умных» и «глупых» компонентов (Smart/Dumb components).
* Отработать передачу данных через пропсы сверху вниз и передачу функций-обработчиков снизу вверх (lifting state up).

## Архитектура и компоненты

Приложение разделено на три функциональных блока:

1. **Portfolio** (Классовый компонент — контейнер состояния)
    * Хранит исходный список всех проектов и текущий активный фильтр.
    * Вычисляет отфильтрованный список проектов.
    * Передает данные и функции-обработчики дочерним компонентам.

2. **Toolbar** (Функциональный компонент — презентационный)
    * Получает через пропсы: список доступных фильтров (`filters`), текущий выбранный фильтр (`selected`) и функцию смены фильтра (`onSelectFilter`).
    * Отображает кнопки категорий. Активная кнопка визуально выделена стилями.

3. **ProjectList** (Функциональный компонент — презентационный)
    * Получает через пропсы массив проектов для отображения.
    * Рендерит сетку карточек с изображениями работ.

## Технологии

* React (v18+)
* JavaScript (ES6+)
* CSS
* Vite (инструмент сборки)

## Запуск проекта локально

1. Откройте терминал в папке проекта.
2. Установите зависимости:

    ```bash
    yarn install
    # или
    npm install
    ```

3. Запустите режим разработки:

    ```bash
    yarn dev
    # или
    npm run dev
    ```

4. Откройте браузер по адресу `http://localhost:5173`.
